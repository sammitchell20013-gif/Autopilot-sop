# Create Hexagon Favicon

## Instructions:

1. Open `Logo.png` in an image editor (Photoshop, GIMP, Figma, etc.)
2. Crop the image to include ONLY the hexagon icon (without the "Autopilot SOP" text)
3. Resize to 512x512 pixels (square) with the hexagon centered
4. Export as `favicon.png` in the `public/` folder
5. The hexagon should have transparent background
6. Recommended format: PNG with transparency

## Quick Option:
If you have the logo in a vector format (SVG, AI), you can:
1. Remove the text layer
2. Export just the hexagon as PNG at 512x512px
3. Save as `public/favicon.png`

Once created, the site will automatically use it as the favicon.
